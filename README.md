\# Algorithms \& Principles of Computer Science



Coursework project for the "API, Algoritmi e Principi dell'Informatica" course at Politecnico di Milano (grade: 30/30).



\## What it does

Implements a SAT solver based on the DPLL algorithm with an integrated VSIDS (Variable State Independent Decaying Sum) heuristic for variable selection. The problem is modeled as boolean satisfiability: given a list of dishes and each employee's preferences, the program searches for a menu that satisfies every employee. If no such menu exists, the least important employee is dropped and the search restarts, repeating until a satisfying menu is found for the remaining employees.
